Tips for Writing Better YouTube Descriptions

Keep your description relevant to the actual video. Explain the main topic clearly and include useful information that helps viewers understand what they can expect from the video.

Avoid unnecessary keyword repetition or misleading information. A natural and useful description is generally better for viewers than a description written only for search engines.
